# EC-05 — Item thêm từ suggestion (PDP) không bị gợi ý lại ở cart (SRS §8)

**SRS gốc:** "Customer views suggestions on product page, adds suggested item, navigates to cart.
Cart suggestions should NOT re-suggest the just-added item." Kỳ vọng: `evaluateSuggestions` Step 4
(`filterCandidates`) check current cart items; suggestion cache invalidated bởi sự kiện
`cart.updated`.

**Priority:** Must | **Annotation trong SRS gốc:** Done

**Kết luận:** Đúng — 2 cơ chế cấu thành EC-05 (loại item đã có trong cart + invalidate cache khi
cart đổi) đều có test pass thật. Không có integration test literal nào ghép cả luồng
PDP-suggestion-add → cart-suggestions-GET end-to-end trong 1 test, nhưng cơ chế được test riêng lẻ
đầy đủ ở cả 2 nửa.

**Phát hiện phụ — ĐÃ ĐIỀU TRA VÀ FIX (xem [[T-SUGG-01]] / [[T-SUGG-05]]):** lúc làm EC-05, chạy
`suggestion.spec.ts` đầy đủ cho thấy 3 test khác (T-SUGG-01, T-SUGG-05 x2) fail — route trả về
`suggestions: []` rỗng. Khi quay lại làm §10 Acceptance Checklist, đã điều tra: **lỗi nằm ở chính
test cũ**, không phải regression code — test tạo product/variant không set `manage_inventory:
false` và không setup inventory, nên `isProductInStock()` (`pipeline.ts:253-274`) coi là hết hàng →
BR-02 lọc sạch mọi suggestion. Đã sửa `publishedProduct()` helper trong `suggestion.spec.ts` thêm
`manage_inventory: false` → cả 9/9 test trong file pass.
