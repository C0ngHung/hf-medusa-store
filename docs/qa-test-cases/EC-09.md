# EC-09 — Admin deactivate rule trong khi cache còn hiệu lực (SRS §8)

**SRS gốc:** "Admin deactivates a suggestion rule while customers have cached suggestions showing
products from that rule." Kỳ vọng: (a) Cache TTL (5 phút) xử lý eventual consistency — worst case
khách thấy gợi ý cũ tối đa 5 phút; (b) thêm sản phẩm gợi ý đó vào giỏ **vẫn hoạt động** (sản phẩm vẫn
tồn tại, chỉ có rule bị inactive) — **không lỗi** cho khách hàng.

**Priority:** Should | **Annotation trong SRS gốc:** Done

**Kết luận:** Đúng cho cả 2 nửa của yêu cầu:

| Nửa yêu cầu                                        | Trạng thái                                               | Bằng chứng                                                                                                                                                               |
| -------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| (a) Cache TTL 5 phút xử lý staleness               | keep, có sẵn config                                      | `SUGGESTION_CACHE_TTL = 300` (giây) tại `constants.ts` — đã xác nhận trong audit trước, không cần test mới (đây là hằng số cấu hình, không phải logic cần test hành vi). |
| (b) Add vẫn hoạt động, drop attribution, không lỗi | **[test MỚI]** — trước đây chưa có test nào cho case này | Viết test integration mới, pass ngay lần chạy đầu.                                                                                                                       |
