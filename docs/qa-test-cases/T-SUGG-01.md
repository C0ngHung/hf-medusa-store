# T-SUGG-01 — Product with 3 manual suggestions → all shown in order (SRS §10.1 / SUGG-001 Tier1)

**SRS gốc:** "Product with 3 manual suggestions → all 3 displayed in order." Validates
**SUGG-001 Tier 1**. Type: Integration.

**Kết luận: Pass — nhưng test này ban đầu FAIL, đã điều tra và FIX trong phiên này.**

**Chi tiết sự cố + fix:** Khi audit lại lần đầu (lúc làm [[EC-05]]), chạy `suggestion.spec.ts` phát
hiện test này fail — route trả về `suggestions: []` rỗng thay vì 3 sản phẩm. Điều tra: route
`GET /store/products/:id/suggestions` có "degrade contract" (BR-10) tự nuốt mọi lỗi thành `200 []`,
nhưng ở đây không hề có lỗi bị nuốt (log sạch) — nghĩa là workflow chạy xong nhưng tính ra 0 candidate
thật. Truy đến `isProductInStock()` (`evaluator/pipeline.ts:253-274`): nếu variant không có
`manage_inventory: false` VÀ không có inventory item nào → coi là hết hàng → BR-02 lọc sạch. Test cũ
tạo product/variant qua `productService.createProducts(...)` (raw) mà **không set `manage_inventory:
false`** và không setup tồn kho → mọi suggestion bị lọc oan là "hết hàng". Đây là **lỗi trong chính
test cũ**, không phải regression ở code sản xuất. Đã sửa `publishedProduct()` helper trong
`suggestion.spec.ts` (thêm `manage_inventory: false` cho variant) → toàn bộ 9/9 test trong file pass.
